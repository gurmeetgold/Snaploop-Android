# SnapLoop Android launcher asset provenance

The Android launcher runtime image `snaploop_app_icon.webp` is derived from the product-owner supplied 1024×1024 PNG that is byte-for-byte the pinned iOS AppIcon (`4e9c538553ef26346fe856b41c06518abab680d7`).

The separate pinned iOS in-app `SnapLoopBrandMark.png` is a different asset and must not be silently replaced by this launcher artwork without visual-equivalence verification.
